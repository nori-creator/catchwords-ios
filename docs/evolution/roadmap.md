# CatchWords を進化させる順番（2026-11-08 のオーナーの依頼の全部）

最終更新: 2026-11-08 ／ 対象: オーナーと、作業する AI

オーナーの指示: 「全て一つずつ実行していって、最高のクオリティで…本物のアップルのアプリのように」
「過去に作ったものは決して一つも使わないで…一からデザイン、UI、UX 機能を設計して」。

- **1つの機能 = 1つの PR**（変更の提案書）。作る → CI（GitHub の自動の試験と画面の写真）で確かめる → オーナーが写真を見る → 取り込む。
- **一から作る物**: 新しい機能のデザイン・画面・流れ・AI への指示。消した過去の物（Web 版の文字検索・単語帳・日記の見た目・赤ペン）は使わない。
- **そのまま使う物**: アプリの土台（ログイン・図鑑への保存・発音の音声・読みの正しさの点検・復習の仕組み・言語を混ぜない規則）。

## 用語

| 言葉 | 意味 |
|---|---|
| API | アプリが外のサービス（Google・AI など）を呼ぶ窓口。多くは使った分だけ料金がかかる |
| API キー | その窓口を使うための鍵。サーバーにだけ置く |
| OCR（文字認識） | 写真の中の文字を読み取ること。iPhone の中で無料でできる（Apple の Vision） |
| 共有拡張（Share Extension） | 他のアプリ（YouTube・Safari など）の「共有」からこのアプリに文字や画像を渡す仕組み |
| ウィジェット | iPhone のホーム画面・ロック画面に置く小さな窓 |
| 審査ガイドライン | Apple がアプリを出す時に守らせる決まり |

### 1の判断（しらべる）

- **調べた語はホームのアルバムに出さない**（アルバムは自分で撮った写真の思い出のため）。図鑑と復習には入る。後でその物を撮れば、その写真はアルバムに出る。
  変えたい場合は言ってください。
- **今の しらべる は AI で引く**（押してから 1〜3 秒）。打っている間は自分の図鑑の語だけがすぐ出る。
  打つたびに一瞬で出る辞書にするには、使ってよい辞書のデータ（CC-CEDICT など）をサーバーに入れる必要がある。
  CC-CEDICT は英語の意味だけで、量詞はほとんど入っていない（`docs/research/dictionary-apps.md`）。
- 無料の人の上限: 1日 300 回（AI の費用の上限のため）。

## 1つずつの確かめ方

1. サーバー: `npm test`（試験）・`npm run typecheck`（型の確かめ）
2. アプリ: CI がシミュレーター（Mac の中の仮の iPhone）で組み立て、画面の写真を撮る（`ios-check.yml`）
3. オーナーが写真と TestFlight（配る前の試しのアプリ）で確かめる
