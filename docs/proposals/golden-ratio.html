CatchWords で黄金比（1 : 1.618）を使う案

今のアプリの画面で、黄金比を当てはめられる場所を6つ挙げます。どれも「比率を1つに揃えて画面に統一感を出す」ための使い方です。

前提: 黄金比が他の比率より美しく見えるという主張は、心理学の実験では一貫した結果が出ていません。効くのは「画面のあちこちで同じ比率が繰り返されて、まとまりが出る」点です。そのため、1か所だけでなく、文字・余白・写真の比率に同じ数を通して使うと効果が出やすいです。

黄金比で使う数: 1.618（φ）、その逆数 0.618、さらに小さい 0.382。フィボナッチ数 8・13・21・34・55 は、隣同士の比がほぼ 1.618 になります。

案1 単語の詳細: 写真と「場所・単語」を 61.8 : 38.2 に

おすすめ小さな変更

開いた時、見えている高さのうち写真が 61.8%、撮った場所と見出しの単語が 38.2% になるように写真の高さを決めます。今回の変更（写真＝頁の高さから場所と単語の札を引いた分）は、普通の iPhone でだいたい 60% 前後になるので、これを 61.8% にそろえる形です。

下へスクロールした時の縮み方も、今の「半分（0.5）まで」を「0.618 倍まで」にすると、大きい時と小さい時の比がそのまま黄金比になります。

変える所
WordDetailView.heroMaxHeight、shrunkScale
注意
言葉が長い・文字が大きい時は札が高くなり、写真が 61.8% を取れない時がある。その時は今のように札を優先する。

案2 文字の大きさの段を 1.618 倍ずつに

おすすめ中くらいの変更

文字の大きさを 9 → 14.6 → 23.6 → 38.2 → 61.8 の段だけに絞ります。単語の頁の見出しは今 38pt で、すでにほぼ 38.2 です。図鑑の「No.」は 9.5pt でほぼ 9。この段に寄せると、頁ごとに少しずつ違う大きさ（13・14・15・16・17pt など）が減り、見出し・読み・本文の差がはっきりします。

段使う所（例）
61.8キャッチの演出の単語、褒める演出の数字
38.2単語の頁の見出し（今 38）
23.6画面の題（図鑑・復習）、復習の問題の単語
14.6本文・意味・例文の訳・読み
9No.・小さな札
注意
本文 14.6 と 23.6 の間が広いので、ボタンなどの 17pt 前後は「中間の段」として 1つだけ残すのが現実的。読みやすさのため、設定の文字の大きさ（Dynamic Type）は今どおり効かせる。

案3 余白をフィボナッチ数（8・13・21・34）にそろえる

おすすめ中くらいの変更（触る所が多い）

今の余白は 10・12・14・16・18 などが混ざっています。これを 8・13・21・34 の4つに絞ります。隣の数の比がほぼ 1.618 なので、「カードの中（13）→ カードの間（21）→ 区切りの大きな余白（34）」が同じ比で大きくなります。角の丸みも、外のカード 21・中の部品 13 にすると、入れ子の形がそろいます。

変える所
単語の頁のカード（今 14・16）、図鑑のカード（今 12・18・22）、設定の行
注意
画面の幅が 1〜2pt 変わる所があるので、図鑑の4列・チャンクの1行に収める処理を CI の見本画面で確かめる必要がある。

案4 キャッチの演出・褒める演出: 主役を黄金分割の高さに

小さな変更

撮った物の切り抜きを、画面のちょうど真ん中ではなく、上から 38.2% の高さに置きます。下の 61.8% に単語の札・訳・ボタンが入り、目が「切り抜き → 単語 → 訳」の順に下へ流れます。真ん中に置くより、写真が少し上に浮いて見え、下の情報に余裕ができます。

変える所
CatchCelebrationView、PraiseCelebrationView の切り抜きの縦位置
注意
着地の演出（図鑑へ飛ぶ動き）の出発点も一緒に動くので、動きの通り道を確かめる。

案5 図鑑のスライドのカード: 幅 1 : 高さ 1.618

中くらいの変更

カードを黄金長方形にすると、上から正方形を切り取った残りも黄金長方形になります。上の正方形に切り抜き、残りに No.・読み・単語を入れると、写真の枠と文字の枠の比が自然に決まります。トレーディングカードやクレジットカード（約 1 : 1.586）に近い形なので、「集めるカード」らしさも出ます。

変える所
DexCarousel のカードの縦横比
注意
Duo の横長で「入るだけ全部」並べる時、カードが縦に長くなる分、1列に入る枚数が変わる。

案6 アイコン: C と W の2つの輪の大きさを黄金比に

慎重に見た目の変更が大きい

今は同じ大きさの2つの輪です。左（C）を大きく、右（W）を 0.618 倍にすると、「大きな世界から言葉を1つつかまえる」動きが形に出ます。開く演出（輪から C と W が出る）もこの大きさに合わせられます。

注意
アイコンはストアでの見分けやすさに直結し、開く演出・ログイン画面のロゴ・ウィジェットも全部変わる。変えるなら最後に、比べる見本を作ってから。

使わない方がいい所

・Duo の見開き（横長）の左右の分け方: 折り目を真ん中にする決定（10-30）があり、61.8 : 38.2 にすると折り目と境目がずれる。
・iPhone のホームのアルバム: 「どの写真も同じ大きさ」（10-22）と合わない。

進め方の提案

  1. 案1（単語の詳細の 61.8 : 38.2、縮み方 0.618）: 今回の変更の続きで、数字を2つ変えるだけ。
  2. 案3（余白 8・13・21・34）と案2（文字の段）: 画面全体の統一感が一番上がる。触る所が多いので、単語の頁 → 図鑑 → ほかの順に分けて進める。
  3. 案4・案5: 見本を見て決める。
  4. 案6: 最後に、見本の比較を作ってから。
