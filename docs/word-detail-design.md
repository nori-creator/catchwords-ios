# 単語の詳細（台湾華語）— 版24 の設計書（アプリで完全に再現するため）

オーナーが決めた見た目と動きを、iOS の画面で**1対1で**作るための設計書。正は模型の版24
（https://claude.ai/artifact/GWwf6QQp7KQjZSG3tM9g3N の「版24」）。ここに無い値を勝手に決めない — 迷ったら模型を測る。

決定の出どころ: `CLAUDE.md`「チャンクの決定」、`docs/chunk-rules.md` C21〜C24、`docs/language-rules.md`。
数値は pt（iOS の論理単位）。字の大きさは `scaledFont(size:)` を通す（iPhone の文字サイズ設定に追従）うえで、
この画面だけの「文字の大きさ」（下の §9）を掛ける。

## 1. 共通の決まり

### 色（`Theme`）
| 役目 | 値 |
|---|---|
| 項目のカード | `Theme.card`、縁 `Theme.border` 1pt、角 24、内側 16、影 0.04 |
| 項目の中の箱（チャンク・例文・量詞・関連語の1件） | **灰色** `Theme.secondary`（light #EDF2F8 / dark #132032）、角 18、縁なし |
| 学習言語の字 | `Theme.foreground` |
| 該当語（見出し語）| チャンクの中: `Theme.foreground` の黒・太字 800、枠なし。**例文の中: `Theme.primary`（名詞の青）** |
| 品詞の色（チャンクの枠と字、例文の中のチャンク） | 名詞 #0083FF / 動詞 #FF3B30 / 形容詞 #2FA84F / 副詞 #A08A2E（dark はそれぞれ明るい色: #4DA3FF / #FF6B63 / #4CD07D / #D9B850） |
| つなぎの語（很・要・的・在…） | **枠も色も無い黒**。大きさ・太さは該当語と同じ（800）。凡例に出さない |
| 読む人の言語（訳・解説） | `Theme.muted`。訳の中の大事な所は `Theme.foreground` の 600 |
| 番号 | **数字だけ**（E 案）: 17pt・700・`Theme.muted` の 80% |

### 発音ボタン（`PronounceCircle`）
- 見出し語だけ 50pt の青い丸（白い印）。ほかは **34pt（例文・関連語は 30pt）の薄い青**（`Theme.primary` 12%、印は
  `Theme.primaryInk`）。押した時・鳴っている間だけ濃い青。**押せる範囲は 44pt**（見た目より広く取る）。
- **縦の位置は「読む字の中心」に合わせる**（ピンインが上に乗っても、ボタンは字の真ん中）。SwiftUI では、行を
  `HStack(alignment: .chunkText)` にし、字の `Text` に `.alignmentGuide(.chunkText) { $0[VerticalAlignment.center] }`
  （`ChunkLineView` に既に在る `chunkText` と同じ）、ボタンにも同じ guide を付ける。見出し語・チャンク・関連語・量詞・
  例文（1行目）のすべてで同じ。模型では測って 0pt のずれ。
- 長押し（0.45 秒）で、設定の速さの **0.7 倍**。押している間、ボタンの上に「0.7×」。

### 読み（注音 / ピンイン）
- 見出し語・チャンク・関連語・量詞: 設定の「発音表記」（`reading.pref`）に従う。描き方は `ZhuyinWordView` /
  `PinyinRubyLine` のまま（注音は字の 0.3 倍・字の右に縦・灰色 / ピンインは 0.36 倍・字の上・灰色）。
- **チャンクの中の該当語（水晶手鍊）は注音を出さない**（ピンインの設定の時はピンインを出す）。
- **例文の読み**（オーナー 2026-10-25「注音の設定のときは例文にピンイン書かなくていい」）:
  - 設定が**注音** → 例文には**読みを出さない**（注音もピンインも無し。字だけ）。
  - 設定が**ピンイン** → 例文の字の上にピンイン（描き方は今の `SentenceRuby` のまま）。
  - `SentenceRuby` に `showReading: Bool`（= `reading.pref == .pinyin`）を足す。false の時は読みの行を作らず、
    行の高さも読みの分を取らない（字だけの行送り）。

## 3. 使い方チャンク（`ChunkCard` — 今の `chunkCard` を作り直す）

```
[灰色の箱]  1   [戴]＋ 水晶手鍊                          (🔊)
               水晶ブレスレットを**つける**            💡
               (💡 を押すと) 💡 戴 は身につける物ぜんぶ…
```
- 1つのチャンク = 1つの灰色の箱（角 18、内側 上下 10・右 12・左 8、箱の間 10）。
- 行: 番号（幅 28）・チャンク（残りの幅）・発音ボタン。3つとも**字の中心の高さ**。
- チャンク: `ChunkLineView` の枠と ＋ の形（字 24pt・700、枠の内側 4/12、最小の高さ 52、角 12）。
  - 品詞の枠: 背景は品詞の色 9%（灰色の箱の上なので `Theme.card` と混ぜる）、縁は 35%、字は品詞の色。
  - 入れ替えられる語: 点線の枠（縁 60%）。**矢印（⌄）は出さない**。押すとホイール（今のまま）。
  - 該当語: 枠なし・黒・800・注音なし。つなぎの語: 枠なし・黒・800。
  - ＋: 字の 0.7 倍・灰色、字の中心の高さ。
  - **決して改行しない**: 入らない時は ①まず枠の内側と ＋ の空きを詰める（`tight`）②それでも入らない時だけ全体を縮める
    （下限 75% — それ以下になるチャンクはサーバが作らない: 4パーツ・8字以内）。`ViewThatFits` に縮めた版を並べる。
- 訳: チャンクの下（左は番号の右に揃える）、16pt・`muted`、大事な所は `foreground` 600。入れ替えると訳も替わる（今のまま）。
- 電球: 訳の右に白黒の電球（線の印 18pt、押せる範囲 36pt）。押すと下に「💡＋ひと言解説」（15pt、白黒の電球を前に）。
  もう一度押すと閉じる。**解説（`usage_chunks[].note`）が無い古い語は電球を出さない。**
- 並び: サーバが返した順（= ネイティブが最も自然・頻繁 → 実用性 → 優先度）。端末で並べ替えない。
- 番号を押す: そのチャンクを使った例文があれば、その例文へ移り、例文の箱を一瞬（1.2 秒）青い縁で光らせる。無ければ押せない。
- 凡例: 一番下に 名詞・動詞・形容詞（出てきた品詞だけ。つなぎの語は出さない）。品詞の名前は一般的な呼び方
  （`ChunkKind.label`: 状態動詞 → **形容詞**、助詞・前置詞 → 前置詞 など）。
- 初めてアプリを使う時だけ（**単語ごとではない**、`UserDefaults` に1回）: 最初の点線の語の下に黒い吹き出し
  「点線の枠の語は、押すとほかの語に入れ替えられます」＋「OK」。OK か点線の語を押すと二度と出ない。

## 4. 例文（`ExampleCard`）
```
1
[灰色の箱]  我 每 天 都 戴 水晶手鍊，聽 說        (🔊)
            可 以 帶 來 好 運。
            毎日水晶のブレスレットをつけてるの。…
```
- 番号は**箱の外の左上**（箱は番号の下）。番号の数字はそのチャンクの番号（例文の並びの番号ではない）。
  読み上げ（VoiceOver）は「チャンク{1}を使った例文」。チャンクを含まない例文は番号を出さない。
- 箱: 灰色、角 18、内側 12/12/12/14、箱の間 14。
- 文: 19pt。読みは §1（注音の設定では無し / ピンインの設定では字の上）。**チャンクの部分は品詞の色・700**（動詞は赤、該当語は青）、ほかは黒。
- **チャンクは文の中でも決して改行しない**（1つの塊として折り返す）。語の途中でも改行しない（今の `Sentences.unbreakable`）。
- **必ず2行以内**: 19pt で2行に入らない時だけ 1pt ずつ小さくする。**下限は画面上で 16pt**（文字の大きさの設定に
  関係なく、画面に出る大きさで 16 より小さくしない）。サーバは例文を **24字以内**にする（§10）ので、iPhone の幅では
  下限まで縮めずに入る（模型で 24字・特大まで測った）。下限でも入らない時だけ3行（記録に残す）。
  SwiftUI では、大きさ 19→16 の版を `ViewThatFits(in: .vertical)` 相当で試すか、`Layout` で行数を数えて決める。
- 発音ボタン: **1行目の右端**、1行目の字の中心の高さ。2行目から下は箱の幅いっぱいに字を並べる
  （ボタンは1行目だけ場所を取る — 文の頭に右寄せの空きを作る）。
- 訳: 文の下、14pt・`muted`。

## 5. 量詞
灰色の箱。`一條` は黒 800、`水晶手鍊` は灰色 400、26pt。入らない時は縮める（改行しない）。右に発音（34pt、字の中心）。
下に注（15pt・`muted`）。

## 6. 類義語・反義語・関連語
```
[類義語]                         ← 色の札（箱の上、左）
[灰色の箱]  手環   ブレスレット                 (🔊)
            腕輪全般（スマートウォッチの…）
```
- 種類の札は**箱の上**（12pt・700、角 7）: 類義語 = 緑（字 #12805C / 地 #E3F5EC）、反義語 = 橙（#C2410C / #FFEDE3）、
  関連語 = 紫（#6D4AC9 / #EFEAFB）。dark は明るい字・暗い地（模型の値）。
- 箱: 灰色、角 14。語 24pt・700＋読み。**訳（`related_words[].gloss`）は語の右、16pt 空けて、15pt・`muted`**。発音は右端。
- 下に違いの解説（`note`、14pt・`muted`）。**電球は出さない。**
- 訳が無い古い語は訳を出さない（語と発音だけ）。

## 7. 台湾メモ
- ノートの罫線: 1行ごとに薄い黒の線（light rgba(11,18,26,.13) / dark rgba(242,246,248,.16)）、行の高さ = 罫線の間隔
  （15pt・行送り 1.95 倍）。**左の赤い縦線・絵文字・印は無し。**
- 強調は**青いマーク**（地 `Theme.primary` 16%、字 `Theme.primaryInk` 700）。**今のデータには強調する範囲が無いので、
  初めはマークを出さない。** 足す時は、本文（`taiwan_note`）に記号を混ぜず、別の欄（例: `taiwan_note_marks: [{start,end}]`）
  にする — 本文に `**` を入れると、今配っているアプリでは記号がそのまま見えてしまう。
- 文ごとに改行し、文と文の間は1行あける。

## 8. 実際の使われ方
- 今の iOS 版の6つのリンク（YouTube で聞く・YouGlish で発音例・Dcard で見る・Threads で見る・**Google検索**・
  教育部國語辭典簡編本）を **2列**に（間 8、1つ 最小の高さ 56、角 16、灰色の地、縁 `Theme.border`）。
- 「台湾のサイトで検索」→「**Google検索**」（URL は今のまま、台湾の検索結果）。
- アイコンは 32pt の角丸（角 8）: YouTube・Threads・Google は各社のロゴの形（Assets に SVG を入れる。
  各社のブランドの決まりに沿う: 形・色を変えない、ほかの物と組み合わせない）。Dcard は青地に白、教育部は臙脂地に白い本、
  YouGlish は自社のロゴではない YouTube の形を使わない（青い丸の再生の印）。
- 押すとブラウザで開く（今のまま）。

## 9. 右上の設定パネル（`SectionsPanel` を作り直す）
今と同じく一番上の行の右の「つまみ」ボタンから、ボタンの下にポップオーバーで開く（幅 352、高さは画面の 78% まで、
中はスクロール）。見た目は**アプリの設定画面と同じ部品**: 見出しは `SettingsCard` の灰色の小見出し、白い角丸のカード、
`SettingsToggle`（青いスイッチ）、`ChoicePills`（選んだ物が青く光るカプセル）。

| 区切り | 中身 | 保存 |
|---|---|---|
| 見出し | 青い丸の印＋「表示する項目と順番」＋右に「既定に戻す」 | — |
| 項目 | 各項目 = 青い丸の印・名前・**青いスイッチ（表示 / 非表示）**・≡（押したまま動かして並べ替え）。説明「スイッチで表示・非表示、≡ を押したまま動かして並べ替え」 | `CardPrefsStore`（今のまま） |
| 復習 | `SettingsToggle`「復習モード」（説明「押すまでぼかし、押すと答えが出る」）＋ `ChoicePills`「ぼかす所」: 訳 / 台湾華語 | `@AppStorage("detail.review")`, `("detail.reviewHide")` |
| 文字と音 | `ChoicePills`「文字の大きさ」: 小 0.85 / 標準 1 / 大 1.15 / 特大 1.3 と、その下に見本（戴水晶手鍊 / 訳）が選んだ大きさで出る。`ChoicePills`「発音の速さ」: 0.6× / 0.8× / 1.0× / 1.2× と「この速さで聞く」 | `("detail.textScale")`, `("detail.speechRate")` |

- 「既定に戻す」: 項目の順と表示、復習（オフ・訳）、文字の大きさ（標準）、発音の速さ（1.0×）を戻す。
- **知っている字の読みを薄くする設定は作らない**（オーナー 2026-10-25 でやめた）。
- 発音表記（注音 / ピンイン）と外観（ダーク）は**ここに入れない**（アプリ全体の設定にある）。
- 文字の大きさ: この画面の字すべてに掛ける（`scaledFont` の後に掛ける倍率）。iPhone の文字サイズ設定は今まで通り効く。
- 発音の速さ: サーバの音声（`AVAudioPlayer`）は `enableRate = true; rate = 速さ`、端末の声（`AVSpeechUtterance`）は
  今の 0.42 に速さを掛ける。長押しはさらに 0.7 倍。
- 復習モード: オンの時、選んだ方（訳 / 台湾華語）を**ぼかす**（`blur(radius: 7)`・`opacity 0.7`）。意味・チャンク・例文の
  訳（または台湾華語の文）が対象。押すとその1つだけ見える。一番上の行に「復習中 {1} / {2}」（見た数 / 全部）。
  ぼかしている間の読み上げ: 「答えはぼかしてあります。ダブルタップで表示」。

## 10. サーバ（`server/`、Supabase の `native-fn`）との約束

| 欄 | 中身 | 古い語 |
|---|---|---|
| `usage_chunks[]` | 並び = 画面の①②③。`parts[]`（text・pos・slot・ja・pinyin・zhuyin・alts）、`ja`（型の訳）、**`note`（ひと言解説、読む人の言語で1文・80字以内）** | `note` が無い → 電球を出さない |
| 程度の語 | 很・超・非常・有點・蠻 は `slot`・`alts` を持たない（サーバが外す）。**端末でも入れ替えにしない**（`isSwappable` は程度の語を常に false — 保存済みの語に alts が残っていても） | 同じ |
| `example_sentence` / `examples_extra[]` | **24字以内**（句読点を除く）、一人称のセリフ、`usage_chunks` の1つを字のまま含む物を先に | 長い文はそのまま（2行以内に縮める。下限で3行） |
| `related_words[]` | `word`・`kind`（syn/ant/rel）・**`gloss`（語の訳、短い）**・`note`（違いの解説）・`reading`・`reading_alt` | `gloss` が無い → 訳を出さない |

例文がどのチャンクを使っているか（番号と品詞の色）は**端末で求める**: 各例文について、チャンクを順に見て、その字
（入れ替えの候補に替えた形も）が例文に字のまま続けて在る最初のチャンク（`ChunkRules.spanText` と同じ探し方）。
色は、その範囲の中の各字に、そのチャンクのパーツの品詞を当てる（該当語は名詞の青、つなぎの語は黒）。

## 11. 表示言語（6つ: 日本語・英語・台湾華語・スペイン語・韓国語・ベトナム語）

- 画面の文字はすべて `L("…")`。新しい文字列 23 個は `strings.json` に 5言語の訳を入れ済み（`scripts/check_l10n.py` が通る）:
  復習モード / 押すまでぼかし、押すと答えが出る / ぼかす所 / 訳 / 文字と音 / 文字の大きさ / 小さいと1画面に多く入る /
  小 / 標準 / 大 / 特大 / 発音の速さ / 長押しはこの 0.7 倍 / この速さで聞く /
  スイッチで表示・非表示、≡ を押したまま動かして並べ替え / 解説 / 点線の枠の語は、押すとほかの語に入れ替えられます /
  OK / Google検索 / チャンク{1}を使った例文 / 復習中 {1} / {2} / 答えはぼかしてあります。ダブルタップで表示 / 押すと使った例文へ。
  既に在る物（類義語・反義語・関連語・名詞・動詞・形容詞・既定に戻す・表示する項目と順番 …）はそのまま使う。
- **サーバが書く欄（訳・解説・関連語の訳）は読む人の言語の物だけ出す**: `ReaderLanguage.clean` に `usage_chunks[].note` と
  `related_words[].gloss` を足す（サーバの `scrubExtrasForReader` と同じ線。日本語・台湾華語の読み手にハングルが多い文は
  違う言語 — 2026-10-25 にサーバをこの線に揃えた）。
- 長い言語（スペイン語・ベトナム語・英語）で崩れない所:
  - 設定パネルの `ChoicePills`: 1つの字幅が足りない時は `minimumScaleFactor(0.7)`（今の部品のまま）。「Extra large」
    「Muy grande」が入ることを確かめる。
  - 例文の番号の読み上げ・「復習中 {1} / {2}」は {n} の差し込みで作る（語順を言語ごとに変えられる）。
  - 実際の使われ方の2列: 名前は2行まで、ブランド名の途中で切らない。
- 共通の表記（TOCFL・NEW・No.・OK・Google・YouTube・Threads・Dcard・YouGlish）は訳さない（R25）。
